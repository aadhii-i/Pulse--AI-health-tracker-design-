# 📖 About

Pulse+ is a modern AI-powered healthcare ecosystem designed to provide an intuitive, accessible, and visually engaging health monitoring experience.

The project showcases a complete end-to-end UI/UX workflow, covering authentication, health analytics, wellness tracking, emergency services, and healthcare management through a production-quality mobile interface.

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/aadhii-i/Pulse--AI-health-tracker-design.git
```

Open the project

```bash
cd Pulse--AI-health-tracker-design
```

Launch locally

```bash
python3 -m http.server 8000
```

Open in your browser

```
http://localhost:8000
```
