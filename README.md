# Pulse+ – AI Health Tracker

A modern AI-powered health tracking mobile application UI/UX prototype.

## Features

- Splash & Onboarding
- Authentication Flow
- Health Dashboard
- Blood Pressure Tracking
- Blood Oxygen Monitoring
- Blood Glucose Tracking
- Nutrition Management
- Hydration Tracking
- Weight & BMI
- Workout Dashboard
- Running Tracker
- Meditation
- Stress Monitoring
- Mood Journal
- Emergency SOS
- Doctor Appointments
- Health Reports
- Notifications
- Premium Subscription

## Tech Stack

- HTML5
- CSS3
- SVG
- Responsive Design
